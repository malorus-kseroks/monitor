# Changelog

## 0.2.0 - Unreleased

- Renamed the package and binary to `kernox-monitor`.
- Replaced the monolithic event loop with typed snapshots and bounded workers.
- Removed plaintext sudo-password storage and shell interpolation.
- Added strict config, `doctor`, shell completions and Windows core support.
- Added capability-aware Linux hardware/service probes and Docker/Podman engines.
- Added bounded container stats/logs, Linux disk rates and fixed-argv service control.
- Added process filtering, four sort modes and sanitized detail views.
- Added responsive, scrollable, multilingual UI with explicit confirmation.
- Restored bounded CPU and memory history charts on both Windows and Linux.
- Updated dependencies and removed the vulnerable legacy lock graph.
