# Workflow: Monitor

## General Principles
- **Мультиязычность:** Все пользовательские интерфейсы и документация должны поддерживать мультиязычность (минимум русский и английский).
- **Качество кода:** Код должен быть чистым, следовать идиомам Rust и проходить проверку `cargo clippy`.
- **Тестирование:** Требуемое покрытие тестами для нового кода — не менее **80%**.

## Development Cycle
1. **Разработка задачи:** Каждая задача выполняется в отдельном цикле.
2. **Фиксация изменений:** Изменения фиксируются (`git commit`) **после каждой выполненной задачи**.
3. **Публикация:** После каждой фиксации выполняется `git push` для синхронизации с удаленным репозиторием.
4. **Сводки (Summaries):** Сводка выполненной задачи записывается **и в метаданные Git notes, и в тело сообщения фиксации (Commit Message)**.

## Commit Message Format
- Формат: `<type>(<scope>): <description>` (например, `feat(docker): add container start button`).
- В теле сообщения должна быть краткая сводка изменений.
