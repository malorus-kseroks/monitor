# Track Specification: Hidden Russian Language

## Overview
Этот трек изменяет поведение переключения языков в приложении. Русский язык становится "скрытым": он больше не участвует в циклическом переключении по клавише `L`, но остается доступным, если пользователь явно укажет его при запуске через флаг `--lang ru`.

## Functional Requirements
- **Исключение из цикла:** Удалить `Language::Russian` из метода `next()` в `src/i18n.rs`.
- **Сохранение доступа:** Оставить поддержку `ru` в парсере аргументов CLI в `src/main.rs`.
- **Скрытие из справки:** Удалить упоминание `ru` из текста помощи для аргумента `--lang` в `src/main.rs`.

## Acceptance Criteria
- При циклическом переключении (клавиша `L`) языки меняются в последовательности: EN -> UK -> DE -> FR -> ES -> EN.
- При запуске `monitor --lang ru` интерфейс отображается на русском языке.
- Если запущен русский язык, при первом нажатии `L` происходит переход на следующий в цикле язык (English), и вернуться на русский через `L` невозможно.
