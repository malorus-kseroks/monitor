# Track: Реализация основного функционала TUI-интерфейса

## Description
Этот трек направлен на создание базового асинхронного терминального интерфейса (TUI) с использованием `Ratatui`. Он должен объединить существующие модули мониторинга (системные ресурсы, Docker) в единое интерактивное окно с поддержкой горячих клавиш и вкладок.

## Scope
- Инициализация терминала и основного цикла приложения на `tokio`.
- Создание макета интерфейса (Layout) с секциями:
    - Мониторинг ресурсов (CPU, RAM).
    - Список Docker-контейнеров.
    - Системные модули (Audio, Network).
- Реализация переключения между секциями/вкладками через горячие клавиши.
- Поддержка выхода из приложения (клавиша `q`).
- Отображение данных в реальном времени с заданной периодичностью.
