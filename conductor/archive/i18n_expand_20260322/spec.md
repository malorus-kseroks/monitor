# Track Specification: Multi-language Support (UK, DE, FR, ES)

## Overview
Этот трек направлен на расширение системы локализации приложения Monitor. К существующим русскому и английскому языкам будут добавлены украинский (UK), немецкий (DE), французский (FR) и испанский (ES). Также будет реализована возможность выбора языка через аргументы командной строки.

## Functional Requirements
- **Добавление языков:** Расширение перечисления `Language` и словаря переводов в `src/i18n.rs`.
- **Локализация UI:** Перевод всех вкладок, заголовков блоков, подсказок горячих клавиш и системных сообщений.
- **CLI аргумент:** Добавление флага `--lang` или `-l` для выбора языка при запуске приложения (например, `monitor --lang uk`).
- **Язык по умолчанию:** Установка английского языка (EN) как языка по умолчанию.

## Non-Functional Requirements
- **Производительность:** Хранение переводов внутри бинарного файла для мгновенного доступа.
- **Масштабируемость:** Структура кода должна позволять легко добавлять новые языки в будущем.

## Acceptance Criteria
- Пользователь может переключать языки в реальном времени клавишей `L` (циклический перебор всех доступных языков).
- Приложение запускается с выбранным языком через аргумент `--lang`.
- Все элементы интерфейса корректно отображаются на новых языках (без обрезки текста, где это возможно).

## Out of Scope
- Автоматическое определение языка системы (локали).
- Поддержка языков с письмом справа налево (RTL).
