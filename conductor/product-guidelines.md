# Product Guidelines: Monitor

## Prose Style
- **Минимализм:** Сообщения должны быть максимально краткими и информативными.
- **Техническая точность:** Использование стандартных терминов (PID, RAM, Docker context) без лишних пояснений.
- **Инструментальный подход:** В логах и ошибках — только факты и статус-коды.

## Visual Identity & Branding
- **Максимальная совместимость и эстетика:** Использование стандартных ANSI-цветов и символов для работы в любом терминале, но с применением современных возможностей `Ratatui` для создания визуально приятного интерфейса.
- **Умеренная акцентировка:** Использование жирного шрифта и инверсии цвета для выделения критических данных вместо избытка ярких цветов.
- **Разделение областей:** Четкое визуальное разделение системных ресурсов, Docker и системных модулей.

## User Experience (UX) Principles
- **Приоритет горячих клавиш (Shortcut-first):** Все основные действия должны быть доступны через клавиатурные сочетания, минимизируя необходимость в навигации стрелками.
- **Предсказуемость навигации:** Использование стандартных паттернов (например, `q` для выхода, `tab` для переключения между секциями).
- **Секционная структура:** Каждая функциональная область (Система, Docker, Модули) должна иметь свой четко выделенный раздел или экран для избежания визуальной перегрузки.
- **Интуитивность:** Интерфейс должен быть понятен без чтения документации для пользователей, знакомых с `htop` или похожими инструментами.
