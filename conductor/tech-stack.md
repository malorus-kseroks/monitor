# Tech Stack: Monitor

## Programming Language
- **Rust (edition 2021):** Основной язык разработки, обеспечивающий высокую производительность и безопасность памяти.

## Frameworks & Libraries
- **ratatui (0.29.0):** Библиотека для создания сложных терминальных интерфейсов (TUI).
- **crossterm (0.28.1):** Кроссплатформенный бэкенд для работы с терминалом.
- **tokio (1.41.1):** Асинхронный рантайм для многопоточности и эффективной работы с I/O.
- **sysinfo (0.33.0):** Кроссплатформенное получение системной статистики (CPU, RAM, Disks).
- **bollard (0.18.1):** Библиотека для взаимодействия с Docker API через Rust.
- **clap (4.5.21):** Мощный парсинг аргументов командной строки с использованием макроса `derive`.
- **chrono (0.4.38):** Работа с датой и временем.
- **futures-util (0.3.31):** Утилиты для работы с асинхронными потоками.

## Architecture
- **Модульная структура:** Основная логика разделена на функциональные модули (`audio`, `bluetooth`, `brightness`, `docker`, `network`, `system`) для упрощения поддержки и расширяемости.
